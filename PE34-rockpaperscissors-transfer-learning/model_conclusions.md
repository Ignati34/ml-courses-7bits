# Выводы по работе моделей

В проекте использован датасет Kaggle `drgfreeman/rockpaperscissors` с тремя классами: `rock`, `paper`, `scissors`. Данные приводятся к формату PyTorch `ImageFolder` и делятся на `train`, `validation` и `test`, чтобы качество модели оценивалось не на тех изображениях, на которых она обучалась.

Были сравнены две стратегии: **ResNet-18 с нуля** и **ResNet-18 с предобученными ImageNet-весами**. Модель с нуля начинает обучение со случайных весов, поэтому ей нужно самостоятельно выучить базовые визуальные признаки: контуры руки, текстуры, фон и форму жеста. Такая модель требует больше эпох, больше данных и больше вычислительных ресурсов.

Transfer Learning показывает преимущество, потому что feature extractor уже обучен на большом наборе изображений и умеет извлекать универсальные визуальные признаки. В проекте заменяется последний классификационный слой под 3 класса, затем при необходимости размораживается блок `layer4` для аккуратного fine-tuning с меньшим learning rate.

Практический вывод: для небольших датасетов изображений лучше начинать с transfer learning, а не с обучения с нуля. Это быстрее, экономит GPU-ресурсы и снижает риск переобучения. В типовом запуске на 3–5 эпохах предобученная ResNet-18 должна дать более высокую validation/test accuracy и более стабильную динамику обучения, чем ResNet-18 с нуля.
